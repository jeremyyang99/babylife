# 👶 婴儿生活管家 (BabyCare)

一款专为 **1 岁以内婴儿** 日常照护设计的本地化生活管理工具。  
采用单文件 HTML 交付，无需安装数据库或后端服务，下载后即可在浏览器中运行。

---

## 🎯 项目目标

帮助新手父母或照护者系统记录婴儿的**喂养、睡眠、换尿布、体温、生长发育、疫苗接种和里程碑事件**，并通过直观的统计图表和筛选功能，轻松掌握婴儿的生活规律与成长趋势。

---

## ✨ 核心功能

### 1. 仪表盘
- 显示各模块记录总数
- 按时间倒序展示最近 10 条活动记录，快速了解最新动态

### 2. 喂养记录
- 记录类型：母乳 / 配方奶 / 辅食
- 记录量（ml 或克）和备注
- 支持按日期排序和搜索

### 3. 睡眠记录
- 记录睡眠时长（分钟）
- 睡眠质量评价：好 / 一般 / 差
- 备注（如入睡时间、安抚方式等）

### 4. 换尿布
- 类型：小便 / 大便 / 混合
- 备注（如颜色、性状等）

### 5. 体温记录
- 体温值（℃）
- 测量部位：腋下 / 口腔 / 肛门
- 备注（如是否发烧、处理方法）

### 6. 身高体重
- 记录身高（cm）、体重（kg）、头围（cm）
- 自动生成生长曲线图（需 Chart.js 支持）

### 7. 疫苗记录
- 疫苗名称、接种部位、反应
- 按时间排序，方便查看接种计划

### 8. 里程碑
- 记录重要发育节点，如抬头、翻身、坐、爬、走、说话等
- 可添加描述和备注

### 9. 统计图表
- 喂养次数趋势（柱状图）
- 睡眠时长趋势（折线图）
- 身高体重曲线（双线图）
- 疫苗接种列表

### 10. 附件管理
- 每条记录均可上传图片、文档等附件（单文件 ≤ 20MB）
- 附件存储在浏览器 IndexedDB 中，支持预览和下载
- 删除记录时自动清理关联附件

### 11. 数据迁移
- 一键导出全部数据（含附件）为 JSON 文件
- 支持导入之前备份的 JSON 文件（覆盖模式）
- 方便换设备或定期备份

## 🖥️ 界面与交互

- **三栏式工作台**：
  - 左侧：导航菜单
  - 中间：列表 / 仪表盘 / 统计
  - 右侧：记录详情面板
- **拖拽调整栏宽**：左右侧栏宽度可自由拖动
- **折叠侧栏**：点击侧栏顶部的箭头可折叠/展开
- **深色/浅色主题**：点击底部月亮/太阳图标切换
- **玻璃质感设计**：柔和、清晰、护眼
